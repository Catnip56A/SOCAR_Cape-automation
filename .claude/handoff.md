- **Nothing is assumed** (carried over, still the core rule): a figure the request does not state loads blank and red; a rate/price may be a number or `NONRECHARG`; Generate lists incomplete rows and leaves them out only if the user confirms; builders raise instead of guessing. Allowance encodings (FLO-EXP-OFF…) are **deliberately left alone — not used** (user, 2026-10-13).
- **Quantity ≤ 0:** Generate warns for any quantity ≤ 0 (values go in as entered); **transport lines ≤ 0 are written but hidden** in the AZN CTR (PDF omits them) and their total cell is 0, so a hidden negative never changes the section total; the section is omitted if every line is ≤ 0. Chosen because the user said "hide", and Excel SUM includes hidden rows.
- **Transport blanks (MA136): option B** — blank Qty/Duration/Unit/Rate stays red and is left out after confirmation. Add the vehicle types in use to `transport_rates` in `template_config.json` so unpriced vehicles are rare.
